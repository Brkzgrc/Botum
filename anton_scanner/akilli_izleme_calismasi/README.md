# Akıllı İzleme Çalışması

Bu klasör, mevcut canlı Scanner’dan bağımsız Akıllı İzleme seçim motorunun geliştirme ve geçmiş replay çalışmaları içindir.

- Mevcut `anton_scanner` dosyaları değiştirilmez.
- Canlı Render, Portfolio ve emir akışı bu klasörden etkilenmez.
- Tamamlanan replay grupları checkpoint olarak korunacaktır.
- Sonuç doğrulanmadan canlı sisteme dağıtım yapılmaz.
- Bu klasör kullanıcı onayı olmadan silinmez.
